# Workflow recipes

- Bug: rstack-mode bug-fix, then tdd when practical.
- Design: how, architect, arena, then rstack-interrogate when a contested choice needs adversarial review.
- Performance: benchmark-checklist, perf-issue or hillclimb.
- Formal invariants: create-formal-verification-skill and statechart.
- Existing verification: maintain-verification-skill or maintain-formal-verification-skill.
- Handoff: recall or session-pickup; decision evidence uses show-me-your-work.
- Reusable work: automate-me. Configured issue pipelines use setup-benny, triage-issue-reports and reproduce-and-fix-issues.

Read each skill with skill_read and only its relevant companions. Installing a recipe does not activate a job.
