# Prompting rstack

Name the desired outcome, repository or evidence source, permission scope and acceptance criterion. For example: "Use rstack to reproduce this bug in the test checkout, fix it, and show the regression check." For investigation: "Use how to explain this subsystem with file references; keep it read-only." For a comparison: "Use arena for two isolated design candidates, then recommend one." For a handoff: "Use recall for this project over the past week and verify the current branch state."
